# Fontes consultadas

As fontes abaixo são estudos de caso publicados pelo fornecedor da plataforma. Por isso, os números foram usados como evidência de que há implementação, mas não como linha de base ou promessa de resultado deste projeto.

## Caso 1 — DPD UK

- Empresa: DPD UK
- Link: [Responding to customer queries faster with Dialogflow](https://cloud.google.com/customers/dpd)
- Data de acesso: 04/09/2026
- Uso no case: chatbot de rastreio; mais de 32% das consultas dos usuários do aplicativo foram tratadas pela experiência conversacional.

## Caso 2 — Hermes Germany

- Empresa: Hermes Germany
- Link: [Cloud Run enables Hermes' Serverless-First transformation](https://cloud.google.com/customers/hermes-germany)
- Data de acesso: 04/09/2026
- Uso no case: plataforma de rastreio com consultas de clientes, chatbots e portais internos; redução publicada de 25% no custo de infraestrutura.

## Caso 3 — TetriXX

- Empresa: TetriXX
- Link: [Removing inefficiencies from global logistics with agentic AI](https://cloud.google.com/customers/tetrixx)
- Data de acesso: 04/09/2026
- Uso no case: agente que usa dados de logística e fontes externas para produzir insights; disponibilidade divulgada acima de 99,99%.
